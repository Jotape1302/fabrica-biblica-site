Política de Privacidade

Última atualização: 14 de outubro de 2026

Dados coletados

Ao autorizar a integração com o TikTok, a ferramenta recebe apenas: identificador da conta (open_id), informações básicas do perfil (user.info.basic) e tokens de acesso necessários para publicar vídeos (video.publish, video.upload).

Uso dos dados

Esses dados são usados exclusivamente para publicar, na conta do próprio titular, os vídeos que ele aprovou, e para consultar o status dessas publicações. Não há coleta de dados de outros usuários, venda, compartilhamento com terceiros ou uso para publicidade.

Armazenamento e segurança

Os tokens ficam armazenados em banco de dados privado, em servidor controlado pelo proprietário, sem acesso público.

Exclusão

O titular pode revogar o acesso a qualquer momento em TikTok › Configurações › Segurança › Apps e serviços. Para solicitar a exclusão dos dados armazenados, escreva para o contato abaixo.

English summary: we only receive the TikTok open_id, basic profile info and access tokens needed to post the owner's approved videos. Data is never sold or shared, is stored privately, and can be deleted on request or by revoking access in TikTok settings.
